🐍 Snake Game in C

A simple terminal-based Snake Game made using the C programming language.
This project is beginner-friendly and perfect for learning basic game development concepts in C.

---

📌 Features

- Snake movement using keyboard
- Random food generation
- Score tracking
- Game over detection
- Simple console graphics
- Easy-to-understand code

---

🎮 Controls

Key| Action
W| Move Up
S| Move Down
A| Move Left
D| Move Right
X| Exit Game

---

🛠️ Technologies Used

- C Programming
- GCC Compiler
- Console/Terminal

---

▶️ How to Run

Step 1: Compile the Program

gcc snake_game.c -o snake_game

Step 2: Run the Game

snake_game
